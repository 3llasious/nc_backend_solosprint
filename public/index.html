THE EXPOSÉ: OFFICIAL API MENU

Welcome Fellow Dev, I beleive documentation for devs should be as readable and easy to navigate as user interfaces are. So please see the available endpoints by method by clicking the expand butons on the relevant card below. Each method will also include examples (so you know what what responses to expect from the server - happy hunting!)

GET: routes

GET
All Topics /api/topics
  • 200

    Returns array of topic objects

  • 500

    msg: "Path not found"

Returns all topics from the database.

GET
All Articles /api/articles
  • 200

    Returns array of topic objects

  • 500

    msg: "Path not found"

Returns all articles from the database.

GET
Get an Article /api/articles/:arti_id
  • 200

    Returns an object of article information

  • 404

    msg: "ID not found"

  • 500

    msg: "Path not found"

Returns an article from the database.

GET
Get Comments on this Article /api/articles/:arti_id/comments
  • 200

    Returns array of comment objects

  • 404

    msg: "ID not found"

  • 500

    msg: "ID not found" : Check your article Id is valid

Returns all comments on a particular article from the database.

GET
All Users /api/users
  • 200

    Returns array of user objects

  • 500

    msg: "Path not found"

Returns all users from the database.

POST: routes

POST
Post a Comment /api/articles/:arti_id/comments
  • 201

    Returns newly created comment object

  • 404

    msg: "ID not found" : Check your article Id is valid

  • 500

    msg: "Path not found"

Posts a new comment to a specific article. Request body must include body and author fields.

PATCH: routes

PATCH
Upvote/Downvote an Article /api/articles/:arti_id
  • 200

    Returns array of topic objects

  • 404

    msg: "Id not found"

Increments or decrements the vote count on an article. Send { inc_votes: 1 } to upvote or { inc_votes: -1 } to downvote.
