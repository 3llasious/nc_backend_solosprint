POST: routes

POST
Post a Comment /api/articles/:arti_id/comments
  • 201

    Returns newly created comment object

  • 404

    msg: "ID not found" : Check your article Id is valid

  • 500

    msg: "Path not found"

Posts a new comment to a specific article. Request body must include body and author fields. 

// request body
{
  "body": "Oh, I've got compassion running out of my nose!",
  "author": "butter_bridge"
}

// response body
{
  "comment": {
    "comment_id": 19,
    "article_id": 3,
    "author": "butter_bridge",
    "votes": 0,
    "body": "Oh, I've got compassion running out of my nose!",
    "created_at": "2024-01-01T00:00:00.000Z"
  }
}

PATCH: routes

PATCH
Upvote/Downvote an Article /api/articles/:arti_id
  • 200

    Returns array of topic objects

  • 404

    msg: "Id not found"

Increments or decrements the vote count on an article. Send { inc_votes: 1 } to upvote or { inc_votes: -1 } to downvote. 

// request body — upvote
{ "inc_votes": 1 }

// request body — downvote
{ "inc_votes": -1 }

// response body is article object with updated vote count
{
  "article": {
    "article_id": 3,
    "votes": 1,
    "title": "Eight pug gifs..."
  }
}
